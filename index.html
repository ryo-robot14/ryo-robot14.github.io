CanSat · 2024

CanSat Koshien

缶サイズの模擬人工衛星「缶サット」を用いた宇宙工学・組み込みシステム開発プロジェクト。 モデルロケットによって上空へ打ち上げられたCanSatが、 降下・着地するまでの間にセンサデータを取得し、 ミッション達成を目指すシステムを開発した。

GitHub ↗ Presentation (YouTube) ↗ Document ↗

My Role

チームリーダーとして、開発全体の設計方針・進行管理・技術統括を担当しました。
Autodesk Fusionを用いた缶サット機構設計、3Dプリント部品設計を行いました。
限られたサイズ・重量制約の中で、安定したデータ取得と降下後の動作を実現するため、機体内部構造やセンサ配置を繰り返し改善しました。
取得したログデータを直感的に理解することができるwebページを作成しました。
技術資料の制作、打ち上げ事前プレゼンの動画の作成の一部なども行いました。

Project Detail

私たちのチームは、大規模災害発生時、孤立地域にいる被災者の状況を一元的に把握できるシステムを缶サットを通じて実装しました。

缶サットのサイズや重量の制約が多く機体内部のレイアウトの最適化が課題となった。 1度の打ち上げで散布できる子機数を増やすことと安全な速度で降下すること、センサ誤動作を抑えることを実現するため、缶サットやパラシュートの設計を繰り返し検討しました。

取得したGPSデータとテキストデータの解析と直感的に把握できるように可視化を行いました。

RCJ Soccer Lightweight · 2025

Toin Sigma

RCJ Soccer Lightweight部門に向けた自律型サッカーロボットの開発プロジェクト。高速移動性能・整備性・安定性を重視し、機械・回路・制御を統合したシステム設計を行いました。

GitHub ↗ TDP ↗

My Role

チームリーダーとして、開発全体の設計方針・進行管理・技術統括を担当しました。
Autodesk Fusionを用いたロボット機構設計、3Dプリント部品設計、CNC加工データ作成を行いました。
KiCadを用いた回路設計、基板レイアウト、はんだ付け・組み立てを担当しました。
ベースコードの設計・管理を行い、チーム全体で開発可能なソフトウェア環境を構築しました。
TDP(プレゼンポスター)の制作、資金・部品調達なども行いました。

Project Detail

高速移動時の加速性能向上を目的として、モーター駆動用電源の昇圧システムを設計・実装しました。

発熱・重量増加・スペース制約など複数の課題に対して、基板レイアウトや内部構造を繰り返し最適化しました。

最終版までに5回以上の全面設計変更を行い、実機検証を繰り返しながらセンサ配置や重量バランスを改善しました。

Philosophy

Why Hardware

私の開発のモチベーションは、「おもしろい」と感じるシステムを実際に形にすることにあります。

モーター・センサ・回路・ソフトウェアが相互に作用しながら動作するロボットシステムに強い魅力を感じています。

特に、アイデアを実際に動作するロボットとして実装し、試行錯誤を重ねながら改善していく過程に大きな面白さを感じています。

今後は医療ロボティクスや人間支援システムの分野において、より高度なロボットシステムの研究・開発に取り組みたいと考えています。
